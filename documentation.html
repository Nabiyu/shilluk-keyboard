Keyboard Layers

Understanding the Layout

The keyboard uses different layers to provide access to Shilluk characters.

A

Normal

The standard keyboard layer for normal lowercase typing.

Ä

Shift

Use Shift to access uppercase and additional Shilluk characters.

ä

AltGr

AltGr provides access to accented and language-specific characters.

⌨

Windows

Designed for comfortable Shilluk typing across Windows applications.
